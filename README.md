# Análise de Dados de Vendas

Projeto de análise exploratória de dados desenvolvido em Python, com foco na manipulação, organização, análise e visualização de dados de vendas.
O projeto utiliza uma base de dados em formato CSV contendo informações sobre pedidos, produtos, clientes, categorias, regiões, vendas, quantidades, descontos e lucros.

## Objetivo

O objetivo deste projeto é aplicar conceitos de análise de dados utilizando Python para extrair informações relevantes de uma base de vendas.
Entre as análises realizadas estão:
- vendas por categoria;
- vendas por região;
- comportamento das vendas ao longo dos meses;
- identificação das categorias, regiões e períodos com maior volume de vendas.

## Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Base de Dados

Os dados utilizados estão armazenados no arquivo `vendas.csv`.
A base contém informações como:
- pedidos;
- datas das vendas;
- clientes;
- produtos;
- categorias e subcategorias;
- regiões;
- valores de vendas;
- quantidades;
- descontos;
- lucros.

## Análises Realizadas

### Vendas por Categoria

Os dados são agrupados por categoria para calcular e comparar o volume total de vendas.
As categorias presentes na análise são:
- Technology
- Furniture
- Office Supplies

### Vendas por Região

As vendas também são agrupadas por região, permitindo comparar o desempenho entre:
- West
- East
- Central
- South

### Vendas por Mês

As datas dos pedidos são tratadas para permitir a análise das vendas ao longo dos meses.
Essa análise permite observar a variação do volume de vendas durante o período disponível na base de dados.

## Visualização dos Dados

O Matplotlib é utilizado para representar graficamente os resultados das análises.
As visualizações permitem comparar os dados de forma mais clara, facilitando a identificação de diferenças entre categorias, regiões e períodos.

## Conceitos Aplicados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:
- leitura de arquivos CSV com Pandas;
- exploração de conjuntos de dados;
- seleção e manipulação de colunas;
- agrupamento de dados;
- ordenação de resultados;
- manipulação de datas;
- análise de vendas;
- criação de gráficos com Matplotlib;
- interpretação de resultados.

## Como Executar

Com Python instalado, instale as bibliotecas necessárias pelo terminal:
pip install pandas matplotlib
Mantenha o arquivo `vendas.csv` na mesma pasta do arquivo Python responsável pela análise.
Depois, execute o projeto pelo terminal do Visual Studio Code:
python analise_vendas.py
